# 🛒 MERN Full Stack E-Commerce Website

A complete **MERN Stack E-Commerce Application** built using **React JS, Node JS, Express JS, and MongoDB**.  
The project includes **user authentication, OTP verification, payment gateway integration, session handling**, and a full shopping workflow.

---

## 🚀 Features

### 👤 User Features
- User Registration & Login
- OTP-based Email/Mobile Verification
- Secure Session-based Authentication
- Password Encryption using bcrypt
- Product Browsing & Searching
- Add to Cart / Remove from Cart
- Checkout & Order Placement
- Online Payment Integration
- Order History Tracking

### 🛍️ Admin Features
- Admin Authentication
- Add / Update / Delete Products
- Manage Orders
- Manage Users
- View Payment Status

---

## 💳 Payment Gateway
- Integrated secure online payment gateway
- Handles payment success & failure states
- Payment confirmation before order creation

---

## 🔐 OTP Verification
- OTP sent during user registration or login
- OTP validation before account activation
- Improves security and prevents fake accounts

---

## 🧠 Session Management
- Session-based authentication using cookies
- Secure user sessions
- Auto session expiration
- Protected routes for users and admins

---
